# Minecraft Web

A Minecraft-inspired voxel game that runs in the browser, built with Three.js and Vite.

## Play locally

Start the dev server, then open the link:

```
npm install
npm run dev
```

Local link: http://localhost:5173/

This link only works on the computer running the dev server. Others need to clone the repo and run it themselves.

## Controls

- **WASD** move, **mouse** look, **Space** jump, **Ctrl** sprint, **Shift** sneak
- **Left click** break, **right click** place, **middle click** pick block
- **1-9** or **mouse wheel** select hotbar slot
- **E** inventory and 2x2 crafting, **F** fly (creative), **G** toggle creative
- **Esc** pause

## Features

- Procedural terrain with hills, beaches, water, trees, and snow caps
- Inventory with stacks, 2x2 crafting (Oak Planks, Glass)
- Health with fall damage, death screen, and respawn
- Creative mode with unlimited blocks and flight
- Day/night cycle

## Scripts

- `npm run dev` start the dev server
- `npm run build` production build into `dist/`
- `npm run preview` serve the production build
- `npm test` headless terrain, collision, and raycast checks
